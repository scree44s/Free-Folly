# Free-Folly

#Welcome to Free Folly!

#This repository is a free to use archive of audio that is ready to use in any Game Dev, Animation, Film or other project!

#Keep in mind that this is a living Archive, and will likely grow and change over time, so check back every so often to see what is new!


#How to navigate:

#We will break out all folders with a master list of each subcategory and sound in this readme file, so check here for what you are looking for first before digging through the folder system!

#If you don't see a sound you are looking for, feel free to post information on it as an issue, or join us as a collaborator to add sounds you recorded to the repo!
